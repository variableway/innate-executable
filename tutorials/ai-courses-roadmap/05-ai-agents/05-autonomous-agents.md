# Lesson 5: Autonomous Agents (Self-Directed)

Agents that create their own tasks. This is the logic behind "BabyAGI" and "AutoGPT."

## Resources

### GitHub
- [yoheinakajima/babyagi](https://github.com/yoheinakajima/babyagi) – The original 100-line script. It is the cleanest implementation of the `Task Creation` → `Task Prioritization` → `Execution` loop.

### Articles
- [AutoGPT Logic Explained](https://pbs.twimg.com/media/Ftqlb_aXwAIsF9i?format=jpg&name=large) – (Image/Diagram) Visualizing the infinite loop of an autonomous agent.

### YouTube
- [Building an Autonomous Agent in Python](https://www.youtube.com/watch?v=5qQHHccrOGs) – Explains the "stack" data structure used to manage the agent's todo list.

### Projects
- Build a script that takes a goal ("Research the history of pizza"), breaks it into 3 sub-tasks, executes them, and writes a report to a file.

## Key Concepts
- Task Creation → Task Prioritization → Execution loop
- Self-directed goal pursuit
- Stack-based task management
- How BabyAGI and AutoGPT work
