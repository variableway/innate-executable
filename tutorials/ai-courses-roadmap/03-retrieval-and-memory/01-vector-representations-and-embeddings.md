# Lesson 1: Vector Representations & Embeddings

Before you can search, you must turn text into numbers. Understanding _how_ these vectors capture meaning is the first step.

## Resources

### Articles
- [The Illustrated Word2Vec](https://jalammar.github.io/illustrated-word2vec/) – Jay Alammar again. This is the visual bible for understanding how words become vectors.

### GitHub
- [nicolas-ivanov/tf_word2vec](https://github.com/nicolas-ivanov/tf_word2vec) – A clean, no-nonsense implementation of Word2Vec using basic TensorFlow/Python. It helps you see the "skip-gram" logic.

### Notebooks
- [Word Embeddings from Scratch](https://pytorch.org/tutorials/beginner/nlp/word_embeddings_tutorial.html) – PyTorch's official tutorial on implementing N-Gram language modeling to generate embeddings.

## Key Concepts
- Word2Vec and skip-gram models
- How words become vectors
- Semantic meaning in vector space
- Embedding dimensions and similarity
