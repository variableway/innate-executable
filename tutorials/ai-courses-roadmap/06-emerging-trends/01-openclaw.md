# Lesson 1: OpenClaw (The "Life OS" Agent)

OpenClaw (often stylized with the lobster emoji) is a proactive, local-first AI assistant. Unlike typical bots that wait for you to prompt them, Clawdbot runs 24/7 on your hardware and messages you first via WhatsApp, Telegram, or Discord.

## Resources

### GitHub
- [openclaw/openclaw](https://github.com/openclaw/openclaw) – The official repository. A "Claude with hands" that manages your email, calendar, and system files.

### Websites
- [OpenClaw Official Site](https://openclaw.ai)
- [OpenClaw Documentation](https://docs.openclaw.ai/start/getting-started)

## Key Concepts
- Proactive AI assistants (messages you first)
- Local-first architecture
- System integration (email, calendar, files)
- Multi-platform messaging (WhatsApp, Telegram, Discord)
