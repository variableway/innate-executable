# Lesson 2: NanoBot

NanoBot is a lightweight version of OpenClaw. An Open Source framework for building MCP agents—complete with reasoning, system prompts, tool orchestration, and rich MCP-UI support.

## Resources

### Websites
- [NanoBot Official Site](https://www.nanobot.ai)

## Key Concepts
- Lightweight agent framework
- MCP (Model Context Protocol) agents
- System prompts and tool orchestration
- Rich MCP-UI support
