# Lesson 5: Vision Transformers (ViT)

Connecting text to pixels. How Transformers process images by treating them as sequences of patches.

## Resources

### GitHub
- [lucidrains/vit-pytorch](https://github.com/lucidrains/vit-pytorch) – Phil Wang (lucidrains) is a legend for implementing papers days after release. This is the cleanest ViT implementation in existence.

### YouTube
- [Vision Transformer from Scratch in PyTorch](https://www.youtube.com/watch?v=ovB0ddFtzzA) – A step-by-step implementation that shows how to chop images into "patches" (tokens).

## Key Concepts
- Image patches as tokens
- Positional encoding for 2D images
- How Transformers process visual information
- Vision vs NLP Transformer architectures
