# Lesson 4: Code Models / Completion Models

LLMs trained on code datasets rather than English text. Essential for AI-powered development tools.

## Resources

### GitHub
- [salesforce/CodeGen](https://github.com/salesforce/CodeGen) – While a large repo, looking at their data preprocessing (tokenizing code) is invaluable.

### Tutorials
- [How to Fine-Tune a Language Model on Code](https://huggingface.co/docs/transformers/tasks/language_modeling) – Using the Hugging Face ecosystem to specialize a base model (like DistilGPT2) for code completion.

### Datasets
- [The Stack (BigCode)](https://huggingface.co/datasets/bigcode/the-stack) – Not a model, but the resource you need to build a code model. It's a massive collection of permissive source code.

## Key Concepts
- Tokenizing code vs natural language
- Fine-tuning base models for code
- Code-specific datasets and preprocessing
- How AI coding assistants work at the model level
