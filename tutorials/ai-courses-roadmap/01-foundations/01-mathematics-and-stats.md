# Lesson 1: Mathematics & Stats

The "logic" of AI. You need to understand how data is transformed and how "learning" is quantified.

## Resources

### GitHub
- [dair-ai/Mathematics-for-ML](https://github.com/dair-ai/Mathematics-for-ML) – A massive, community-curated collection of papers and notes for AI math.

### Articles
- [The Matrix Calculus You Need for Deep Learning](https://explained.ai/matrix-calculus/) – A brilliant, visual guide by Jeremy Howard and Terence Parr that bridges the gap between simple calculus and neural networks.

### YouTube
- [3Blue1Brown – Essence of Linear Algebra](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab) – The absolute best visual intuition for vectors and matrices.

### Notebooks
- [Mathematics for Machine Learning (DeepLearning.AI)](https://github.com/m-bashari/Mathematics-for-Machine-Learning-and-Data-Science-Specialization) – Lab notebooks that apply linear algebra and calculus using Python/NumPy.

## Key Concepts
- Linear algebra (vectors, matrices, transformations)
- Calculus (gradients, derivatives)
- Statistics and probability
- How "learning" is quantified mathematically
