A two-agent CrewAI flow that turns a one-line brief into a polished email.

## Quick start

```bash
cd agents/05-email-drafting-agent
pip install -r requirements.txt
export OPENAI_API_KEY=...
python agent.py --brief "follow up on Q3 invoice to ACME Corp"
```

## Flow

```
Brief ──▶ Writer ──▶ Editor ──▶ Polished email
```

Each agent has a tight `role` / `goal` / `backstory` so the tone stays consistent regardless of input.
