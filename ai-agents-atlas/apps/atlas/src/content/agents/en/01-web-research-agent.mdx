A LangGraph agent that searches the web for any topic and synthesizes a structured research report.

## Quick start

```bash
cd agents/01-web-research-agent
pip install -r requirements.txt
cp .env.example .env   # add OpenAI + Tavily keys
python agent.py --query "latest advances in AI agents 2024"
```

Free API keys:
- OpenAI: [https://platform.openai.com/api-keys](https://platform.openai.com/api-keys)
- Tavily: [https://app.tavily.com](https://app.tavily.com) (free tier available)

## Architecture

```
User Query → [Search Node] → Tavily Web Search → [Synthesize Node] → GPT-4o → Report
```

Two nodes, one entry point, no cycles. State is typed `ResearchState` so each node operates on a small surface.
